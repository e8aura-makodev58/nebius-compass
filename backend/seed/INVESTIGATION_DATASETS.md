# Synthetic investigation seeds (N3b)

These files contain synthetic application state, not recorded live model responses.
Neither is installed into an existing runtime room automatically.

## Small lifecycle dataset

`investigation-lifecycle.json` is a four-hour workflow exercise generated by:

```
node backend/seed/create-investigation-dataset.mjs
```

It builds the disclosed SC-01 public history in an isolated store, submits a synthetic
operator report, confirms and approves its first fix through the real service, then submits
an empty report and a smoke report. Audit timestamps are pinned to simulation time. The
normal offline generator advances to `2026-10-01T12:00:00Z`, with `AUTO_APPROVE_SAFE`, share
one and template narrator fallback. No API or credential access occurs.

| AUTO_APPROVED | 2 |
| ABSTAINED | 7 |
| ESCALATED | 1 |

Sample IDs: **INV-0001** approved, **INV-0002** abstained, **INV-0003** escalated. The file
is about 249 KB. No outcomes were forced or repaired to match a desired score.

## Regenerated plant-1 month

`investigation-month/plant-1.json` plus its `.json.history/` directory is a separate
candidate month seed. Keeping the existing `demo-control-rooms/plant-1` seed unchanged
preserves the paired-replay comparison dataset while the main agent reviews this policy run.

Reproduction (input is the original week snapshot, not runtime data):

```
git show 962ac7f:backend/seed/demo-control-rooms/plant-1.json > .cache/n3b-week-source.json
node scripts/generate-demo-history.mjs --from .cache/n3b-week-source.json --out .cache/n3b-month.json --until 2026-10-06T08:00:00Z --investigation-share 0.2
```

Generated from `2026-09-08T02:17:45.245Z` through `2026-10-06T08:00:00Z`: 41,755 ticks,
612 total issues, 833 completed attempts, 593 archived issues, zero fetch/credential reads,
about 14 seconds in the recorded run. The live file is 5,685,835 bytes; nine archive files
total about 10.9 MB, with the largest about 2.8 MB. Each committed file is under 20 MB.
The live JSON SHA-256 is `cbe696a4b4f576464216adb43257b1d9601be13288cd5ed3259538aa7061e9f3`.

| AUTO_APPROVED | 23 |
| EXPIRED | 2 |
| ABSTAINED | 1 |

There is no fabricated hazard in simulated narration. For an escalation example use the
small dataset's explicitly submitted synthetic smoke report. Samples in the month include
INV-0003 (auto-approved), INV-0010 (abstained), and INV-0002 (expired); some other approved
runs are archive-backed.

The unattended floor reaches its ten pending-issue cap after failed approved attempts and
unsupported investigations accumulate. The policy does not authorize retries under a
consumed approval or override abstention; operators must explicitly override or
re-investigate those issues. Consequently the last weeks contain little new work. This is
an honest policy result, **not** an improvement over the existing month and not a suitable
replacement for its held-out last-week comparison without reviewing the evaluation cohort.

To inspect this candidate with `createLiveStore`, pass the archive root explicitly as
`backend/seed/investigation-month/plant-1.json.history`. To copy it as a runtime room, copy
the state, its archive, and any later journal together, using the normal seed/bootstrap
workflow; never overwrite an existing company room from this file.

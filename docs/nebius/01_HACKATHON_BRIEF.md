# Nebius x NVIDIA Global AI Hackathon — Brief

> Source: Hackathon brief supplied by the participant in chat, October 18, 2026. This is a faithful structured transcription of that brief, not the legally controlling rules. Refer to `02_OFFICIAL_RULES.md` if the two differ.

## Welcome

Build a working AI system on open, independent infrastructure, and own the whole thing. The NVIDIA x Nebius Global AI Hackathon is for AI builders, ML engineers, founders, and anyone shipping practical, high-performance AI. You'll build with NVIDIA open source models served on Nebius through Nebius Token Factory, on high performance GPU infrastructure. Experiment with new ideas, push the boundaries of open source AI, and submit a project for a chance to win prizes and recognition.

Join fellow builders for technical onboarding, casual workshops, team formation, focused build time, and feedback as you participate in the Global AI Hackathon. [Find your nearby city/event here](https://luma.com/builderandbrews?k=c).

## Requirements

### Challenge

All submissions must run on either Nebius Token Factory or Nebius AI Cloud and use at least one NVIDIA open source model. Everything else is up to you.

### Tracks

#### Coding and Agentic Engineering Track

Build coding agents and developer tools: agents that write, run, and test code in Token Factory.

#### Best Apps and Agents Track

Build any app or agent someone would actually use, from a productivity tool or copilot to a workflow that runs itself. Power it with Nemotron models on Nebius through Token Factory. Reach for Nemotron 3 Ultra when you need serious reasoning, and let Nano or Super handle the fast, everyday calls, so your app stays responsive and your credits stretch further. Deployment using Nebius Serverless Endpoints or background processing via Serverless Jobs is encouraged but not required.

#### Personal AI Track

Build an always-on private assistant with persistent memory, reusable skills, chosen tools/information, and execution across daily workflows. Use an NVIDIA open source model, with tools such as NVIDIA NemoClaw, OpenShell, Hermes Agent, and Nebius Serverless.

#### Physical AI Track

Build embodied and edge agents that sense and act in the real world: robotics, IoT, and on-device intelligence, powered by Nemotron, GROOT, Cosmos, and Sonic models and coordinated through an agent runtime. Nebius Serverless Jobs can support simulations, synthetic data, policy evaluation, or sensor processing; Serverless Endpoints can support real-time inference. Video: at least one minute of working hardware/robot footage or, if no physical hardware, key application modules in action.

### What to submit

- **Working project:** An NVIDIA Nemotron or other NVIDIA open source model on Nebius Token Factory or Nebius AI Cloud, meeting track requirements.
- **Category:** Select the best-fitting track.
- **Project description:** What you created, why you created it, and how it works.
- **Working demo:** URL to working demo/hosted application/test build (Physical AI exempt).
- **Demo video:** Public YouTube video **under three minutes**, showing functioning project and use of Nebius and NVIDIA models. Physical AI has a one-minute footage/module requirement.
- **Public repository:** Public GitHub/GitLab/Bitbucket URL, open-source license (MIT, Apache 2.0, or MPL 2.0), README, setup/run instructions, source and needed assets. Explain NVIDIA model use, Token Factory benefits, and Nebius services used.
- **Feedback:** On Nebius Token Factory/AI Cloud and NVIDIA tools/models/technologies used.
- **Pre-existing project disclosure:** Explain significant updates made during the Submission Period if the project predates it.
- **IRL city event:** Select attended Builders & Brews city for City Winner Award eligibility, if applicable.

Review the complete [Official Rules](https://nebiusglobalaihackathon.devpost.com/rules).

## Reuse clarification

The rules explicitly allow projects existing before the Submission Period **if significantly updated after the period begins**. A copied/forked repository alone is not a significant update. Entrants must describe the significant changes and comply with sole ownership, licensing, and public-repository requirements.

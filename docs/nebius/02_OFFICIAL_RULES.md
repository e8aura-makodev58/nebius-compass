### Project Requirements

**What to Create:** A working software application that runs on either **Nebius Token Factory or Nebius AI Cloud**, uses **at least one NVIDIA open source model**, and fits one of the four tracks.

**“Runs on Nebius Token Factory or Nebius AI Cloud”** means the project makes a runtime call to the **Token Factory inference API**, or is deployed/run using Nebius AI Cloud compute (**Serverless Jobs, Serverless Endpoints, or DevPods**).

**Tracks:**

- **Coding and Agentic Engineering Track:** Coding agents/developer tools that write, run, and test code in Token Factory.
- **Best Apps and Agents Track:** Useful applications and agents, from copilots to autonomous workflows. Power with Nemotron models on Nebius through Token Factory. Nemotron 3 Ultra for intensive reasoning; Nano/Super for fast routine calls. Serverless Endpoints or Jobs are encouraged but **not required**.
- **Personal AI Track:** Always-on private assistant with persistent memory, reusable skills, selected tools/data, and ability to act across workflows, using NVIDIA open-source model(s) and optionally NemoClaw, OpenShell, Hermes Agent and Nebius Serverless.
- **Physical AI Track:** Embodied/edge agents for robotics, IoT and real-world sensing/action using models such as Nemotron, GROOT, Cosmos, Sonic and agent runtime. Serverless Jobs for simulation/synthetic data/evaluation/sensor processing; Endpoints for inference. Demo video includes at least one minute of operating hardware/robot, or key modules in action where no hardware is involved.

**Functionality:** Project must successfully install and run consistently on intended platform and work as represented in video/description.

**Platforms:** Submitted project must run on the specified intended platform.

**New & Existing:** “Projects must be either newly created by the Entrant or, if the Entrant’s Project existed prior to the Hackathon Submission Period, must have been significantly updated after the start of the Hackathon Submission Period. Entrants should explain how their Project was significantly updated during the Submission Period.”

**Third Party Integrations:** Entrant must be authorized under applicable licenses/terms to use integrated SDKs, APIs, and data.

### Submission Requirements

- Qualifying project built with required developer tools.
- **Working URL:** Hosted demo, working application or test build (not required for Physical AI submissions).
- **Text description** of features and functionality.
- **Public repository URL** on GitHub, GitLab, or Bitbucket containing source code, assets, instructions necessary for functionality.
- Public **open-source license** (e.g., Apache 2.0, MIT or MPL 2.0), detectable/visible at repository top/About.
- README with setup and run instructions; highlight NVIDIA Nemotron/other NVIDIA open source model use, where Token Factory accelerated the workflow, and any Nebius services used.
- **Public YouTube demo video under three minutes** (judges need not watch beyond three minutes) showing the project functioning on its intended device and linked on submission form. No unlicensed third-party trademarks/copyrighted audio or material. Physical AI: at least one minute of actual hardware/robot operating or, absent hardware, key modules in action.
- Identify exactly which **track** is being entered.
- Give feedback on Nebius Token Factory/AI Cloud and NVIDIA models/tools/technologies used.
- For a pre-existing project, **written explanation of significant updates during Submission Period**.

**Multiple Submissions:** More than one submission permitted, but each must be unique and **substantially different** from the entrant's other submissions, as determined by Sponsor/Devpost in their sole discretion.

**Submission Ownership:** Project must be original work, **solely owned** by entrant, and not infringe others' IP or other rights.

**Testing:** Entrant must provide access via functioning site/demo/build; for private sites provide login credentials in test instructions. Project must remain available **free of charge and unrestricted** for Sponsor, Administrator, Judges through end of Judging Period. Judges may decide based on submitted descriptions, images, videos without running software. For proprietary/third-party hardware not widely available (other than typical smartphone/tablet/desktop), Sponsor/Administrator may require physical access on request.

**Language:** All materials in English or accompanied by English translations (video, description, testing instructions and all other materials).

**Team Representation:** Team/organization must appoint an authorized eligible individual Representative, who warrants authority to act for the team/organization.

**Intellectual Property:** Entry must be entrant/team/organization original work and solely owned, without rights/interests held by others; not violate copyright, trademark, patent, contract, privacy or other third-party rights. Third-party contractors may give technical assistance if entrant owns resulting components and submission remains result of entrant's ideas/creativity. Open-source dependencies/hardware are allowed if licenses complied with and new software enhances/builds on the underlying project's features/functionality.

**Financial or Preferential Support:** Submission may not have been developed or derived from a project receiving financial/preferential support from Sponsor/Administrator, including funding/investment, contract development, or commercial licenses from Sponsor/Administrator before end of Submission Period. Sponsor may disqualify if a real/apparent conflict arises from awarding a prize.

## 6. Judges & Criteria

A Sponsor-selected judging panel evaluates eligible entries; judges may be employees/third parties, need not be publicly named, and may change. One or more judging rounds/panels are allowed.

**Stage One (pass/fail):** Baseline viability; genuine fit for track and reasonable application of required APIs/SDKs. A superficial rebrand of unrelated work does **not** qualify.

**Stage Two (equally weighted criteria):**

1. **Technological Implementation:** How effectively project is built and uses Nebius Token Factory/AI Cloud models and NVIDIA Nemotron/other NVIDIA open source models.
2. **Design:** Complete coherent product experience, rather than only technical proof-of-concept.
3. **Potential Impact:** Credible, specific real problem and audience; demonstrated solution addresses it.
4. **Quality of Idea:** Creative/non-obvious use of required infrastructure/models and evidence of genuine domain understanding.

Scores determine potential prize winners, in judges' sole/absolute discretion.

**Feedback:** Feedback submissions evaluated for completeness, viability and potential impact.

**Ties:** Higher score in first applicable criterion wins, followed sequentially by later criteria; if still tied, judge panel votes.
